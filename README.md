# 🛒 스마트 가격 비교기 (Smart Unit Price Calculator)

마트나 편의점에서 쇼핑할 때, 용량이 다른 제품이나 할인 행사가 적용된 제품 중 어떤 것이 더 가성비가 좋은지 실시간으로 비교해 주는 정적 웹 도구입니다.

## ✨ 주요 기능 (Features)
- **다중 할인 완벽 지원:** 1+1, 2+1, % 행사 내역을 반영한 실제 100단위 당 가격 계산
- **다국어 지원:** 한국어, 영어, 중국어, 일본어, 프랑스어 지원
- **개인정보 무수집:** 서버 통신 없이 기기(브라우저) 내에서만 구동되는 안전한 클라이언트 앱
- **모바일 친화적 UI:** Tailwind CSS를 활용한 직관적인 뷰와 다크모드 지원

## 🛠️ 기술 스택 (Tech Stack)
- HTML5
- Vanilla JavaScript
- Tailwind CSS (CDN)

## 🚀 배포 (Deployment)
Cloudflare Pages를 통해 자동 배포 및 호스팅됩니다.
